# Lab 04 Web Implementation Plan

> **For agentic workers:** Use executing-plans inline, with final independent review.

**Goal:** Extend the existing Flask app with real SPICE DC/AC/transient and evidence.
**Architecture:** Existing route/form dispatches to original analytical module or
the starter adapter. Local SVG plotting consumes solver arrays, no CDN required.
**Tech Stack:** Flask/Jinja, Python stdlib/unittest, HTML/CSS/JS/SVG, Playwright MCP.
**Spec:** `docs/superpowers/specs/2026-11-24-lab04-web-design.md`

## Global Constraints
- Preserve three analytical modes and existing tests; reuse diagrams/adapter/model.
- SPICE only for CE divider, default handout values, model disclaimer visible.
- Never invent output or return stale charts on failure. No shell=True.
- No public deployment, push, global package installs, or unrelated cleanup.

## Review Focus
- Switching analysis must ignore hidden irrelevant inputs, but reject invalid modes.
- Failed engine/input following success must remove old results and success state.
- NaN, infinity, invalid numbers, unsupported analysis/mode must not launch solver.
- Chart series and engineering values must come from the same actual solver run.
- 390 px layout, keyboard labels and Running/Success/Error must remain usable.
